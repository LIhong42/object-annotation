# 参数化标注色 mask 提取

构建脚本对所有 image2 标注图使用同一套颜色参数化迟滞提取算法。调用方必须传入 `red`、`green`、`black`、`white`、`blue` 之一；缺省为 `red`。

1. 按所选颜色寻找接近对应纯 RGB 值、且相对配准原图确实发生变化的高置信种子。
2. 彩色标注使用目标通道优势及编辑方向建立软支持；黑白标注使用亮度方向、通道中性和原图差分建立软支持。
3. 从高置信种子仅在连续的同色软支持区域内执行迟滞生长。
4. 只填充同时具有编辑差分证据的封闭纹理孔洞。
5. 不执行会跨越非标注色间隔的闭合、膨胀或组件合并。
6. 对最终区域直接运行连通域分析；每个天然分离的标注色区域对应一个实例。

该算法会排除原图中本来就存在、但在标注图中未改变的同色区域。摘要 `mask_extraction` 记录 `annotation_color`、高置信种子数、颜色变化支持区域、候选连通域数和最终实例数。

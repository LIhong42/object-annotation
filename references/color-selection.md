# 标注颜色选择

每次类别级或单实例级 image2 调用前，先观察原图，并从下列五个固定值中选择一种：

| 参数值 | 填充颜色 | RGB |
|---|---|---|
| `red` | 纯红色 | (255, 0, 0) |
| `green` | 纯绿色 | (0, 255, 0) |
| `black` | 纯黑色 | (0, 0, 0) |
| `white` | 纯白色 | (255, 255, 255) |
| `blue` | 纯蓝色 | (0, 0, 255) |

选择目标是让标注色与目标对象及其紧邻背景的视觉差异最大，同时让原图中与该纯色接近的区域最少。不得选择在目标对象表面或其紧邻背景中占明显比例的颜色。若多个颜色均合格，优先选择在整张原图中出现最少、且与目标边缘两侧均有明显亮度或色相差异的颜色。

模型必须为每次调用记录 `annotation_color` 参数值和一句选择理由。颜色一经选定，该次提示词、image2 输出、manifest 和 mask 提取命令必须使用完全相同的参数值。不得使用表外颜色。

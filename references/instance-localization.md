# 单实例唯一定位规范

在调用 image2 前，先为同类别全部可辨识实例建立固定参考系并验证描述唯一。

## 参考系

- 坐标原点为图片左上角，x 向右、y 向下。
- 图像区域使用九宫格：左上、上中、右上、左中、中央、右中、左下、下中、右下。
- 同类实例按可见区域中心点 x 坐标从小到大排序，称为“从左向右第 N 个”。
- 中心点 x 基本相同时，再按 y 从小到大排序，并写明“同列从上向下第 N 个”。
- 可附加归一化中心坐标，例如“中心约为图宽 61%、图高 64%处”；该坐标只用于定位描述，不作为标注框。

## 描述必需字段

每个 INSTANCE_DESCRIPTION 同时包含：

1. 同类总览与稳定序号：如“画面中 4 把椅子里，从左向右第 3 把”。
2. 九宫格区域或归一化中心。
3. 至少一个稳定参照物及明确方向：如“位于人物左侧、餐桌前缘右半部”。
4. 可辨识外观：颜色、朝向、形状或尺寸。
5. 遮挡/接触关系：如“椅背完整可见，椅腿被桌沿部分遮挡”。

不得只写“餐桌前的红棕色椅子”“左边的椅子”等可同时匹配多个实例的描述。

## 唯一性检查

调用前逐项验证：

- 描述是否只匹配一个同类实例？
- 序号是否按同一中心点排序规则得到？
- 参照物在原图中是否稳定且唯一？
- 描述是否避免“这个、旁边、前面”等缺少锚点的相对词？

任一答案为否时继续增加序号、坐标、锚点或遮挡关系，直到唯一；不得通过重复调用 image2 解决描述歧义。

## 四把椅子的示例

合格描述：

> 画面中 4 把椅子里，从左向右第 3 把；位于中央偏下，中心约为图宽 61%、图高 63%处；处在餐桌前缘右半部、站立人物左侧；红棕色，椅背朝向镜头，椅腿被桌沿部分遮挡。

该描述包含稳定序号、区域、坐标、双重锚点、外观和遮挡关系，可唯一定位。
